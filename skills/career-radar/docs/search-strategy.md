# Search Strategy

Build queries from four groups:

1. **Target roles:** exact titles and close equivalents in Portuguese and English.
2. **Differentiators:** seniority, architecture, technical leadership, or domain terms.
3. **Location:** Brazil, `remote Brazil`, `remoto Brasil`, and explicit eligibility terms.
4. **Freshness:** recent publication or update terms supported by the search host.

For a profile focused on technical leadership and architecture, examples include:

```text
"Tech Lead" remote Brazil Java Spring Kubernetes
"Staff Engineer" remote Brazil distributed systems cloud
"Principal Engineer" Brasil remoto arquitetura software
"Solution Architect" remote Brazil observability AI engineering
```

These are starting points, not a fixed whitelist. Adapt them to the user's resume and preferences. Search results must be opened and checked against the original listing before being reported.
