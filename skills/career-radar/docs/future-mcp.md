# Future MCP Phase

The first release relies on ChatGPT's web research and task history. An MCP server should be added only when the product needs durable state or controlled sources.

Potential tools:

- `save_profile`
- `save_resume`
- `search_jobs`
- `get_new_matches`
- `record_opportunity`
- `get_search_history`
- `update_opportunity_status`

The MCP phase should store canonical URLs, normalized employer and title, first-seen date, last-seen date, status, and the evidence used for evaluation. It must not submit applications automatically.
