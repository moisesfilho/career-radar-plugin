# User Profile Contract

Career Radar is reusable across users. No personal profile is embedded in the Skill.

## Required onboarding fields

- Resume or structured career summary.
- Target roles and seniority.
- Required and preferred skills.
- Location, remote constraints, time zone, and work authorization.

## Optional fields

- Preferred industries and company size.
- Languages.
- Salary expectations.
- Exclusions, travel limits, and availability.
- Minimum compatibility score.

## Schedule fields

- Cadence: daily, weekly, or on demand.
- Execution time and time zone.
- Freshness window.
- Maximum opportunities per report.
- Delivery format.

The profile belongs to the user's host context. Do not copy a profile from examples, repository history, another conversation, or another user. The example files are templates only.
